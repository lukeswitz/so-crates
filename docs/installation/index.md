# Installation Overview

For a private or permanent instance of SO-CRATES, most folks will want our pre-built container image, which is compatible with both Docker and Podman - see the [Docker](docker.md) or [Podman](podman.md) pages.

On Windows or macOS, use [Docker Desktop](docker.md#docker-desktop-windows-macos). On macOS you can also [run natively](macos.md), which additionally allows capturing live traffic and collecting Endpoint Security logs from that Mac.

If you're running [OhMyDebn](ohmydebn.md), it will handle installing Podman and downloading that same container image for you automatically.
