# Interactive Demo

The fastest way to try SO-CRATES is with our online interactive demo:

[https://so-crates.org/demo](https://so-crates.org/demo)

Please note the following:

- This is a cloud-based service so please do not share any sensitive files or any other sensitive info
- Free accounts are limited to 60 minutes of usage before the instance is automatically terminated
- If you need a private or permanent instance of SO-CRATES, then you can proceed to [Installation](installation/index.md) to perform a local installation of SO-CRATES
